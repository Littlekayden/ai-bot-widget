AI 小百科助手示例页面

这是一个示例页面，用于演示 AI 小百科助手问答机器人挂件的使用。

您可以在页面右下角看到机器人挂件图标，点击它即可打开聊天窗口。

使用说明：
  1. 确保后端服务运行在 http://localhost:8081
  2. 点击右下角的机器人图标打开聊天窗口
  3. 在输入框中输入问题并发送
  4. AI 助手会以流式方式返回回答

如何在其他网站中使用：

在您的 HTML 页面中添加以下代码：

<!-- 引入样式文件 --> <link rel="stylesheet" href="ai-bot-widget.css"> <!-- 引入脚本文件 --> <script src="ai-bot-widget.js"></script>

或者使用 CDN 方式（如果部署到 CDN）：

<link rel="stylesheet" href="https://your-cdn.com/ai-bot-widget.css"> <script src="https://your-cdn.com/ai-bot-widget.js"></script>

自定义配置：

如果需要修改 API 地址或其他配置，可以在引入脚本后添加：

<script> // 修改配置（需要在脚本加载后执行） // 注意：当前版本需要在脚本内部修改 config 对象 </script>

功能特点：

  • ✅ 响应式设计，支持移动端
  • ✅ 流式响应，实时显示AI回答
  • ✅ 美观的UI设计，现代化界面
  • ✅ 显示消息时间戳
  • ✅ 用户消息在右侧，AI消息在左侧
  • ✅ 平滑的动画效果
